# Vibe Meet

사용자 프로필과 선호 조건을 기반으로 소개팅 상대를 추천하는 로컬 웹 애플리케이션입니다. 핵심 흐름은 필수 조건 필터링, 항목별 점수 계산, 순위 결정, 추천 이유 설명입니다.

## 사용 기술

- React + TypeScript + Vite
- Framer Motion
- Lucide React
- Recharts
- LocalStorage
- Vitest

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 개발 서버 주소로 접속합니다. 일반적으로 `http://localhost:5173` 입니다.

## 주요 기능

- 내 프로필 생성 및 수정
- 44명 가상 프로필 데이터
- 성별, 나이, 키, 지역, 흡연, 종교 필수 조건 필터링
- 성격, 관심사, 가치관, 데이트 스타일, 연락 패턴 가중치 조절
- TOP 5 추천 및 계산 기반 추천 이유
- 필터링 과정 시각화
- 후보자 비교 및 레이더 차트
- LocalStorage 기반 매칭 기록
- 발표용 테스트 시나리오
- 다크 모드

## 매칭 알고리즘 원리

필수 조건은 하드 필터로 작동합니다. 조건을 통과하지 못한 후보자는 점수와 관계없이 제외됩니다. 남은 후보만 대상으로 5개 항목 점수를 0~100점으로 계산합니다.

점수 항목:

- 성격 및 성향: MBTI 자리별 유사도와 외향성 차이
- 취미 및 관심사: 다중 선택 교집합/합집합 유사도
- 연애 가치관: 가치관 교집합/합집합 유사도
- 데이트 스타일: 활동성 차이와 선호 데이트 유형 유사도
- 연락 및 생활 패턴: 연락 빈도 차이와 음주 성향

## 점수 계산 공식

```text
정규화 가중치 = 각 가중치 / 전체 가중치 합계 * 100
최종 점수 = Σ(항목별 점수 * 정규화 가중치 / 100)
```

동점자는 가치관 점수, 나이, 프로필 ID 순서로 결정합니다. 같은 입력에는 항상 같은 결과가 나옵니다.

## 프로젝트 구조

```text
src/
  App.tsx              화면과 상호작용
  data/profiles.ts     기본 사용자, 조건, 44명 가상 데이터
  lib/matching.ts      독립 매칭 알고리즘
  lib/storage.ts       LocalStorage 기록
  lib/matching.test.ts 매칭 엔진 단위 테스트
  styles.css           반응형 UI 및 다크 모드
  types.ts             공통 타입
```

## 테스트 방법

```bash
npm test
npm run build
```

테스트 모드 화면에서 일반 매칭, 엄격한 조건, 후보 없음, 동점 확인, 가치관 가중치, 낮은 점수 시나리오를 바로 적용할 수 있습니다.
